# Store assets (not all committed)

Place Play Console uploads here while preparing release.

| Asset | Path | Spec |
|-------|------|------|
| Phone screenshots | `screenshots/*.png` | 4–8 files; see [docs/play-store/SCREENSHOTS.md](../../docs/play-store/SCREENSHOTS.md) |
| Feature graphic | `feature_graphic.png` | 1024×500 px |

PNG/JPEG files in this folder are **gitignored** so large binaries stay local. Copy paths from here when uploading to Play.
