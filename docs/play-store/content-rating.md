# Google Play — Content rating (IARC)

Start from **App content → Content rating → Start questionnaire**.

Typical answers for **PromptVault** (local prompt utility, no social/UGC):

| Topic | Suggested answer |
|-------|------------------|
| Category | Utility, productivity, or communication helper (pick closest) |
| Violence | None |
| Sexuality | None |
| Language | None (user-written prompts are not moderated by the app) |
| Controlled substances | None |
| User interaction / sharing | No chat or public sharing in v1 |
| User-generated content shown to others | **No** — content stays on device |
| Online content | **No** in-app browsing of third-party feeds |
| Gambling | No |
| Ads | No |

If asked about **unrestricted internet** or **WebView**: the app may open HTTPS links (privacy policy) via the system browser; prompts are not loaded from the web.

Apply the generated rating to all targeted countries. Save certificate ID in Play Console for your records.
