# Per-task plans

One markdown plan per EPICS task **before** implementation code.

| File | Task |
|------|------|
| `<ID>.plan.md` | Implementation plan for that task ID |

Template: [docs/TASK_PLAN_TEMPLATE.md](../../../docs/TASK_PLAN_TEMPLATE.md)

Tracked in [.cursor/sprint-state.json](../../sprint-state.json): `planFile`, `planStatus` (`draft` | `approved`).
